# Weekly Incident Report Builder

주간 장애공유 보고서(Excel 집계 + PowerPoint 리포트)를 **원클릭으로 자동 생성**하는 도구
— 엑셀 피벗·카운트·차트 갱신부터 지난주 대비 PPT 작성까지 한 번에.

## 📸 주요 기능

### 📊 Excel 데이터 자동 집계 (`update_excel.py`)
- 원본 데이터 시트 기준으로 **모든 피벗 테이블 새로고침 + 전체 재계산** (Excel COM 사용)
- 부서별 / 부서별·계열사별 시트의 **월별 장애 건수 카운트 수식을 기준일이 속한 달까지 자동 생성**
  (없는 달은 기존 셀과 동일한 서식 — 글꼴·테두리·채우기·표시형식 — 을 그대로 복제)
- 라인 차트의 계열 범위를 **기준월까지 자동 확장**
- 원본을 건드리지 않고 `기존파일명_YYYYMMDD.xlsx`로 **백업 후 인플레이스 갱신**
- 대상 파일이 Excel에 **열려 있으면 잠금을 감지해 중단** → 낡은 데이터로 리포트가 생성되는 사고 방지

### 📑 PowerPoint 리포트 자동 작성 (`make_ppt.py`)
- 갱신된 엑셀 + **지난주 PPT(템플릿 겸 비교본)** → 이번주 장애공유 PPT 생성 (python-pptx)
- **최근 3개년 추이 라인차트**: 외부 링크 차트라 XML 캐시를 직접 재작성(트렌드라인·마커·서식 보존),
  연도 구분 음영·라벨을 포인트 수 변화에 맞춰 **각 연도 1월 경계에 자동 정렬**
- 전사 / 부서별 / 계열사별 추이 차트 + **요약·증감 문구 + 기준일** 자동 반영
- 지난주 PPT와 비교해 **신규 등급확정 장애 표 자동 작성**,
  신규발생·협의중 표에서 이번주 확정된 건을 **자동 삭제**하고 건수 갱신
- 상세 목록을 **등급(1→2→3등급 이하 그룹) → 발생일 순**으로 재정렬,
  한 페이지를 넘치면 **상세 슬라이드 자동 추가**, 행 추가·삭제로 흐트러진 표 테두리 정규화

### 🖥️ 웹 런처 (`launcher.py`) — 무설치
- **표준 라이브러리만으로** 동작하는 localhost 전용 웹 UI (외부 노출 없음)
- 화면 입력: **기준일 + 원본 엑셀 + 지난주 PPT** → **① 엑셀 / ② PPT / 전체 실행** 버튼
- **찾아보기** = Windows 네이티브 파일 선택창, **진행 로그 실시간 표시**, 완료 후 결과 파일·폴더 열기
- 중복 실행 방지 · 결과 저장 위치 자동 지정(엑셀=원본 자리, PPT=지난주 PPT 폴더)

### 📦 배포용 exe (Python 설치 불필요)
- PyInstaller onedir 번들 → 폴더 복사 후 `.exe` 더블클릭이면 실행 (단, Microsoft Excel은 필요)

### ⚙️ 설정 외부화
- 부서명·파일명·서체 등 **환경 고유 값을 `report_config.json`으로 분리**
- `report_config.sample.json`을 복사해 실제 값을 채우는 방식 (실제 설정 파일은 저장소에 포함하지 않음)

## 🗂 파일 구조

```
weekly-incident-report/
├── update_excel.py            # 엑셀 집계 자동 갱신 (Excel COM)
├── make_ppt.py                # 주간 장애공유 PPT 생성 (python-pptx)
├── launcher.py                # 로컬 웹 런처 (무설치 UI, 표준 라이브러리)
├── appconfig.py               # 환경 고유 설정 로더
├── report_config.sample.json  # 설정 예시 (복사 → report_config.json 작성)
├── requirements.txt
├── *.bat                      # 더블클릭 실행용 런처
└── README_*.md                # 엑셀/PPT 단계별 상세 문서
```

## 🚀 실행 방법

### 방법 1: 웹 런처 (권장 · 무설치)
```bash
# 실행용 .bat 더블클릭 → 브라우저에서 화면 입력 후 버튼 클릭
```

### 방법 2: 배치 파일 (cmd)
```bash
엑셀_업데이트.bat --date 2026-08-05
PPT_생성.bat      --date 2026-08-05 --prev "지난주_장애공유.pptx"
```

### 방법 3: 파이썬 직접 실행
```bash
python update_excel.py --date 2026-08-05
python make_ppt.py --date 2026-08-05 --prev "지난주_장애공유.pptx"
```

> 최초 1회: `report_config.sample.json`을 `report_config.json`으로 복사하고
> 부서명·파일명 등 실제 값을 채우세요.

## 📋 사전 요구사항
- Windows + **Microsoft Excel / PowerPoint** (피벗 새로고침·차트 갱신·결과 확인에 COM 사용)
- Python 3.11 + `openpyxl`, `pywin32`, `python-pptx` (전용 가상환경 권장)

## ⚡ 자동화 규칙 요약

| 입력 | 처리 | 결과 |
|------|------|------|
| 기준일 | `요약` 시트 기준일 설정 + 피벗/재계산 | 최신 집계 반영 |
| 원본 엑셀 | 월별 카운트 수식·서식·차트 범위 자동 확장 | 인플레이스 갱신 + 백업 |
| 지난주 PPT | 차트·요약문구·신규확정/정렬 자동 작성 | `YYYYMMDD_장애공유.pptx` |

## 📝 배경

매주 **장애 데이터를 손으로 취합해 엑셀 집계를 갱신하고, 다시 PPT 보고서를 그리는** 반복 작업에서 출발했습니다.
피벗 새로고침 → 월별 카운트 수식 추가 → 차트 범위 확장 → PPT 차트/문구/표 갱신까지,
매번 같은 손작업을 반복하며 실수(빠진 달·낡은 데이터·정렬 누락)가 생기던 지점을 하나씩 자동화했습니다.

핵심 인사이트는 **"보고서 작성을 사람의 손이 아니라 데이터 파이프라인에 맡기자"** —
원본 데이터만 최신이면, 집계·차트·리포트는 버튼 하나로 항상 같은 품질로 재생성됩니다.
```
수작업 취합 → 반복되는 실수 → "매주 하는 손작업을 파이프라인에 심자"
```
