# 장애 주간보고 – PPT 생성

`update_excel.py`로 갱신된 엑셀을 읽어, **지난주 장애공유 PPT(=템플릿 겸 비교본)**의
차트·요약문구·제목을 채워 이번주 주간보고 PPT(`YYYYMMDD_장애공유.pptx`)를 만든다.

> ⚙️ 최초 1회: `report_config.sample.json` 을 `report_config.json` 으로 복사하고
> 사업부명·파일명 등 실제 값을 채우세요. (`report_config.json` 은 git에 올라가지 않습니다)

## 🖥️ 웹 런처 (권장 · 무설치)
cmd 대신 브라우저 화면에서 실행하는 방법. **`장애보고_실행.bat` 더블클릭** → 브라우저가 자동으로 열림.
- 표준 라이브러리만 사용(추가 설치 없음). **내 PC에서만(localhost) 동작** — 외부 노출 없음.
- 화면 입력: **기준일** + **원본 엑셀** + **지난주 장애공유 PPT** (템플릿/출력폴더는 지정 불필요)
- **찾아보기** = Windows 네이티브 파일 선택창(PowerShell WinForms)
- 버튼: **① 엑셀 업데이트 / ② PPT 생성 / 전체 실행(①→②)**
- **진행 로그 실시간 표시**, 완료 후 **결과 파일·폴더 열기** 링크, **종료** 버튼
- 저장 위치: **엑셀은 원본 자리(인플레이스, 백업 생성)**, **PPT는 지난주 PPT 폴더**에 `YYYYMMDD_장애공유.pptx`
- 파일: `launcher.py` (+ `장애보고_실행.bat`). 종료는 화면의 '종료' 또는 콘솔 창 닫기.

### 📦 배포용 exe (파이썬 설치 불필요)
- `JangaeReport_배포.zip` 을 풀면 나오는 **`JangaeReport` 폴더 전체**를 복사 → `JangaeReport.exe` 더블클릭.
- Python·venv 설치 없이 실행됨(PyInstaller onedir 번들). 단 **Microsoft Excel은 필요**(피벗 갱신 COM), PowerPoint는 결과 확인용.
- 폴더 통째로 유지해야 함(exe만 떼면 실행 안 됨). 첫 실행 시 SmartScreen 경고 → '추가 정보 → 실행'.
- **재빌드**(코드 수정 후):
  ```
  "%USERPROFILE%\jangae-venv\Scripts\python.exe" -m PyInstaller --noconfirm --onedir --name JangaeReport ^
    --collect-all pptx --collect-all openpyxl --collect-all win32com ^
    --hidden-import win32timezone --hidden-import pythoncom --hidden-import pywintypes launcher.py
  ```
  (`launcher.py`는 `--child` 모드로 exe 자신을 재실행해 update_excel/make_ppt 를 수행하므로 frozen 에서도 실시간 로그가 유지됨)

아래는 개별 스크립트를 직접 실행하는 방법(참고). `--template` 생략 시 `--prev`(지난주 PPT)를 템플릿으로 사용하고, 결과 PPT는 지난주 PPT 폴더에 생성됩니다.

## 실행 순서 (2단계)  — PPT 생성 시 `--prev`(지난주 PPT) 필수
```bash
엑셀_업데이트.bat --date 2026-08-05
PPT_생성.bat      --date 2026-08-05 --prev "지난주_장애공유.pptx"
```
- `--prev` = 지난주 장애공유 PPT (4페이지 신규 등급 확정 장애 비교용, **필수**). 첫 실행은 템플릿을 지난주본으로 사용
- `--date` 생략 시 기준일 = 오늘
- 파이썬 직접 실행: `"%USERPROFILE%\jangae-venv\Scripts\python.exe" make_ppt.py --date 2026-08-05 --prev "..."`

## 무엇을 채우나
| 슬라이드 | 갱신 요소 | 소스 |
|---|---|---|
| 0 | 전사 추이 차트 + 요약문구 2줄 + 증감문구 + 날짜 | `사업부별` 전사(23행), `요약` C22·C23·C24 |
| 1 | 계열사 전사 추이 차트 + 요약문구 + 날짜 | `사업부별_계열사별` 전사(17행), `요약` C135·C136·C137 |
| 2 | 사업부 4개 추이 차트 (제목=사업부명으로 매핑) | `사업부별` 각 사업부 행 |
| 3 | 계열사 사업부 4개 추이 차트 | `사업부별_계열사별` 각 사업부 행 |
| 4 | **신규 등급 확정 장애 표** (지난주 PPT와 비교해 자동 작성) | `데이터` + `--prev` PPT |
| 6~9 | 제목의 등급 건수 `(2등급 X건, 3등급 이하 Y건 총 Z건)` | `요약` C22에서 추출 |

### 4페이지 '신규 등급 확정 장애' 작성 규칙
- 대상 = 이번주 `데이터`(등급확정) 중 **지난주 PPT 상세목록(6p~)에 없는** 건
- **장애명** = `[등급]` + `데이터` 제목
- **장애내용** = 지난주 PPT(4p '신규 발생' → 없으면 5p '협의 중')에서 찾은 값과 `데이터` N열 값 중 **더 긴 텍스트**
- **나머지 칸**(발생일/시간/고객/장애원인/사업부·담당·팀) = `데이터`에서 채움
- **동일 장애 매칭** = 발생일(월/일) + (고객사 부분일치 **또는** 제목 핵심 일치)
  → 엑셀과 지난주 PPT의 고객사·제목 표기가 달라 둘 중 하나만 맞아도 동일로 판단
- 표가 커지면 아래 '신규 발생 장애' 섹션을 자동으로 내려 겹침 방지

### 4·5페이지 '신규 발생 장애' / '등급 협의 중 장애' 정리
- 지난주 이 표들에 있던 건이 **이번주 등급확정**(`데이터`에 추가)되면 해당 건을 표에서 **삭제**하고 제목 `(N건)` 갱신
  - 예) 지난주 '신규 발생'/'협의 중'에 있던 건이 이번주 확정되면 그 표에서 자동 삭제

### 6페이지~ '장애 목록 상세' 재정렬
- 4p 신규확정 건이 상세목록에 없으면 추가 후 전체를 **1등급 → 2등급 → '3등급 이하' 그룹** 순으로 정렬,
  각 그룹 안에서는 **발생일 오름차순**
  - '3등급 이하'(3·4·…등급)는 한 그룹으로 묶어 등급 구분 없이 날짜순 (예: 4등급 7/2가 3등급 7/10보다 앞)
  - 1·2등급은 발생일이 늦어도 상위, 1등급은 최근이라도 최상단
- 제목 뒤 **등급건수 텍스트는 14pt**('장애 목록 상세'는 20pt 유지)
- 한 페이지 용량을 넘으면 **상세 페이지를 자동 추가**(마지막 상세 슬라이드 복제) — 넘친 건도 목록에 포함

### 모든 표 테두리 통일
- 행 추가/삭제로 생긴 **두꺼운 내부 행 구분선**을 가늘고 연한 선(0.5pt, 50% 회색)으로 통일
- 표의 **바깥 아래 테두리**는 두껍게 유지/복원(마지막 행 삭제 시에도)

- 차트는 **작성일 기준 최근 3개년**(= 기준연도−2년 1월 ~ 기준월)을 표시
- 차트는 외부 링크 방식이라 **XML 캐시 값을 직접 재작성**(트렌드라인·마커·서식·연도 배경 보존)
- 0·1p의 **연도 구분 회색 음영과 연도 라벨**은 포인트 수 변화에 맞춰 자동으로 **각 연도 1월 경계에 정렬**
  (템플릿의 기존 밴드 위치로 플롯 기하를 자가 보정 → 새 월 수로 재계산)

## 갱신하지 않는 것 (설계상 범위 / 향후 단계)
- 4p '신규 발생 장애'에 **이번주 신규 발생 건을 새로 추가**하는 로직, 6~9p 상세 표 목록은 아직 미갱신(다음 단계)
  → 4p 신규확정 표가 커지면 아래 '신규 발생 장애' 섹션이 내려가며, 남은 지난주 데이터 기준이라 하단이 다소 넘칠 수 있음(다음 단계에서 정리)
  → 6~9p 제목 총건수(데이터 기준)와 표에 나열된 항목 수가 다를 수 있음
- 슬라이드 2·3의 **노란 원형 강조 주석**은 템플릿의 수동 표시라 위치가 갱신되지 않음
- 요약/증감 문구는 `요약` 시트 값을 그대로 사용
  → `요약` 수식이 만든 `-19% 감소`, `감소/증가` 같은 표현이 그대로 나올 수 있음(엑셀 수식에서 다듬으면 반영됨)

## 환경 재설정 (가상환경이 없거나 깨졌을 때)
> SSL 가로채기 프록시 환경에서 pip이 막히면 `--trusted-host` 옵션이 필요할 수 있음.
```bash
python -m venv %USERPROFILE%\jangae-venv
"%USERPROFILE%\jangae-venv\Scripts\python.exe" -m pip install --trusted-host pypi.org --trusted-host files.pythonhosted.org -r requirements.txt
```
