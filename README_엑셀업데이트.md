# 장애 주간보고 – 엑셀 데이터 업데이트

원본 엑셀(`data` 폴더의 원본 파일 — 파일명은 `report_config.json`에서 설정)을 바탕으로 주간보고용 집계를 자동 갱신한다.
**원본을 `기존파일명_YYYYMMDD.xlsx`로 백업한 뒤, 갱신 결과로 원본을 그 자리에서 덮어쓴다(인플레이스).**
(수작업처럼 원본에 바로 반영하되, 만약을 대비한 날짜별 백업이 같은 폴더에 남는다.)
`--out 경로`를 주면 원본 대신 해당 경로에 저장(백업 없음).

## 무엇을 하나
1. **`요약` 시트 B1(기준일)** 을 지정 날짜(기본: 오늘)로 설정
   → `B2 =IF(B1="",TODAY(),B1)` 가 해당 날짜로 계산됨
2. **모든 피벗 테이블 새로고침**(요약 시트 하단 피벗 차트 포함) + 전체 재계산
3. **`사업부별` / `사업부별_계열사별` 시트 월별 장애 건수 카운트 수식**을 기준일이 속한 달까지 채움
   - `사업부별`
     - 전사 블록: 23행(수식)/22행(월 헤더), `B`열(2024‑01) 시작
     - 사업부 4개 블록: 4·22·40·58행(수식) / 3·21·39·57행(월 헤더), `AO`열(2024‑01) 시작
     - 수식: `=SUMPRODUCT((데이터!A=연도)*(데이터!G="MM")*(데이터!Q="사업부"))`
   - `사업부별_계열사별` (계열사 장애만: `데이터!AJ="Y"` 조건 추가)
     - 전사 블록: 17행(수식)/16행(월 헤더), `A`열(2024‑01) 시작
     - 사업부 4개 블록: 5·24·42·61행(수식) / 4·23·41·60행(월 헤더), `AM`열(2024‑01) 시작
     - 수식: `=SUMPRODUCT((데이터!A=연도)*(데이터!G="MM")*(데이터!Q="사업부")*(데이터!AJ="Y"))`
   - 없는 달은 **동일 패턴 + 기존 월 셀과 동일한 서식**으로 자동 추가
4. 위 데이터를 참조하는 **라인 차트들**의 계열 범위를 기준일 달까지로 확장 (차트별 기존 시작 월은 유지)

> 집계 기준: `데이터` 시트의 `실제시작` 월 (표의 `연도`·`월` 컬럼과 동일)

## 실행 방법
가장 간단한 방법 — 배치 파일 더블클릭 또는:

```bash
엑셀_업데이트.bat
```

날짜를 지정하려면:

```bash
엑셀_업데이트.bat --date 2026-08-05
```

파이썬으로 직접 실행:

```bash
"%USERPROFILE%\jangae-venv\Scripts\python.exe" update_excel.py --date 2026-08-05
```

주요 옵션
| 옵션 | 설명 |
|------|------|
| `--date YYYY-MM-DD` | 기준일 (기본: 오늘) |
| `--src 경로` | 원본 엑셀 경로 (기본: `data\<report_config.json의 excel_filename>`) |
| `--out 경로` | 결과 저장 경로 (미지정 시 원본 인플레이스 갱신 + `기존파일명_YYYYMMDD.xlsx` 백업) |
| `--visible` | Excel 창을 보이게 실행(디버그) |

## 사전 요구사항
- Windows + **Microsoft Excel 설치** (피벗 새로고침·재계산·차트 갱신에 Excel COM 사용)
- Python 3.11 + `openpyxl`, `pywin32` (전용 가상환경에 설치되어 있음)
- 실행 전 대상 엑셀이 **Excel에서 열려 있지 않아야** 함

## 환경 재설정 (가상환경이 없거나 깨졌을 때)
> SSL 가로채기 프록시 환경에서 pip이 막히면 `--trusted-host` 옵션이 필요할 수 있음.

```bash
python -m venv %USERPROFILE%\jangae-venv
"%USERPROFILE%\jangae-venv\Scripts\python.exe" -m pip install --trusted-host pypi.org --trusted-host files.pythonhosted.org -r requirements.txt
```

## 참고 / 주의
- 결과 파일의 `요약` B1/B2 는 **날짜 일련번호**로 기록(시간대 밀림 방지).
- `기준일`이 데이터가 없는 미래 달(예: 8월)이면 해당 월은 `0`으로 표시됨(정상).
- 원본 `데이터` 시트에 신규 장애가 추가되면, 다시 실행하여 피벗/카운트/차트를 갱신하면 됨.
